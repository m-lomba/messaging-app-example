# Android Messaging App Example

A lightweight Android reference app demonstrating real-time chat architecture and messaging workflows.

## Purpose
Created as a clean boilerplate and reference template for implementing real-time messaging, user-to-user chat UI, and background message handling without re-writing initial setup code.

## Tech Stack
* **Language:** Kotlin
* **Architecture:** MVVM, Clean Architecture patterns
* **UI Components:** RecyclerView, Custom ViewHolders for chat bubbles
* **Min SDK:** 21

## Quick Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/m-lomba/messaging-app-example.git
   ```
2. Open the project in **Android Studio**.
3. Run on any emulator or physical device (API 21+).
